Font Dashboard

Finds fonts you downloaded but never installed, including the ones Adobe keeps hidden under names like .30173.otf. macOS, no dependencies.

The dashboard itself runs on your own machine, because installing a font and reading Adobe's cache both need filesystem access that a web page is not allowed to have. This page is the documentation, plus the font inspector below, which does work right here in the browser.

Run it

git clone https://github.com/aditya31Sharma/fontdash.git
cd fontdash
python3 fontdash.py

Opens http://127.0.0.1:8777. Tick what you want, press Install. Python 3.8+, which macOS already ships. Nothing to install.

python3 fontdash.py --dir ~/Downloads --dir ~/Dropbox/Fonts
python3 fontdash.py --no-adobe        # skip the Creative Cloud cache
python3 fontdash.py --list            # terminal, just report
python3 fontdash.py --install-new     # terminal, install everything new

Drop any .otf, .ttf, .ttc or a whole .zip below. It is read in your browser and never uploaded anywhere.

What the notes mean

NoteWhat it means
bestWidest character coverage of the files for that face. Install this one.
incompleteMissing letters, digits or punctuation. Usually a crippled demo.
demoNames itself a demo, trial or personal-use build.
mislabelledA .ttf that is really OpenType/CFF inside, or the reverse.
narrowerA sibling file in the same pack covers more characters.

incomplete is the one that bites. Plenty of free display fonts ship an .otf with letters only, so a price or a date silently renders as nothing and you find out at the proofing stage.

Which file it installs

A pack usually holds .otf, .ttf, .woff and .woff2 of one typeface. Web formats are ignored, since macOS cannot install them. Between the desktop formats the winner is whichever covers more characters, with OpenType/CFF breaking a tie. It is not always the .otf.

Files keep the name they shipped with. Adobe's cache is the exception, because .30173.otf is not a name.

Safety

Nothing is deleted, renamed in place or overwritten. A filename that already exists in ~/Library/Fonts is reported and skipped. The Adobe cache and your scan folders are only ever read, and the local server binds to 127.0.0.1.
